영상에서 제시된 3단계 공식인 [UI 표준 용어 + 원하는 동작 + 구체적인 트리거 및 제약 조건]을 엄격히 준수하여, Claude Code 및 Cursor 환경에서 컨텍스트 누락 없이 바로 복사해 실행할 수 있는 실전 프롬프트 템플릿 모음입니다.

### 레이아웃 영역 (Layout Patterns)

* **히어로 섹션 (Hero Section) & CTA (Call to Action)**
* **프롬프트 템플릿**:
```text
웹사이트 첫 진입 영역에 제품의 정체성을 한눈에 전달하는 [히어로 섹션]을 구성해 줘. 상단에는 서비스 가치를 압축한 헤드라인과 서브텍스트를 배치하고, 우측(또는 하단)에는 고해상도 대시보드 미리보기 이미지를 넣어 줘. 중앙 하단에는 클릭 시 회원가입 폼으로 스크롤 이동하는 눈에 띄는 대비 색상의 [CTA 버튼]을 배치하고, 가로 전체 패딩과 수직 여백을 넉넉히 확보해 줘.

```




* **반응형 레이아웃 (Responsive Layout)**
* **프롬프트 템플릿**:
```text
콘텐츠 목록 영역을 CSS Grid 기반의 [반응형 레이아웃]으로 구현해 줘. 뷰포트 너비에 따라 데스크톱(1024px 이상)에서는 3열, 태블릿(768px~1023px)에서는 2열, 모바일(767px 이하)에서는 1열로 자동 재배치되도록 breakpoint를 설정해 줘. 각 열 사이의 간격(gap)은 24px로 통일하고 카드 크기가 화면 비율에 맞춰 유연하게 리사이징되게 해 줘.

```




* **카드 레이아웃 (Card Layout)**
* **프롬프트 템플릿**:
```text
기능 소개 섹션에 반복되는 정보를 구조화하여 보여줄 수 있는 [카드 레이아웃]을 적용해 줘. 각 카드는 독립된 흰색 컨테이너 박스 형태로 구현하고, 내부에는 상단 아이콘, 중간 볼드 타이틀, 하단 2~3줄 요약 설명이 포함되도록 계층 구조를 잡아 줘. 카드 테두리는 은은한 1px 보더와 8px 라운드 코너(border-radius)를 적용해 줘.

```




* **벤토 그리드 (Bento Grid)**
* **프롬프트 템플릿**:
```text
서비스 주요 기능들을 비대칭 격자 형태로 시각화하는 [벤토 그리드] 레이아웃을 생성해 줘. 가장 핵심적인 데이터 분석 기능은 가로 2칸 x 세로 2칸의 대형 카드로 강조하고, 나머지 부가 기능 4개는 1칸짜리 소형 카드로 배치해 줘. 데스크톱에서는 4x2 그리드를 유지하되, 화면 너비가 768px 미만으로 줄어들면 모든 카드가 동일한 1열 구조로 수직 정렬되게 해 줘.

```




* **사이드바 레이아웃 (Sidebar Layout)**
* **프롬프트 템플릿**:
```text
대시보드 페이지에 좌측 네비게이션과 우측 작업 공간이 분리된 [사이드바 레이아웃]을 구축해 줘. 좌측 사이드바는 폭 260px로 고정(sticky/fixed)하고, 내부 메뉴 클릭 시 전체 페이지 리로드 없이 우측 메인 콘텐츠 영역만 비동기로 변경되도록 라우팅을 구성해 줘. 모바일 환경에서는 사이드바가 숨겨지고 좌상단 햄버거 메뉴를 누르면 토글되게 해 줘.

```




* **스티키 헤더 (Sticky Header)**
* **프롬프트 템플릿**:
```text
페이지 상단 글로벌 내비게이션 바를 [스티키 헤더]로 구현해 줘. 사용자가 페이지를 아래로 길게 스크롤하더라도 뷰포트 최상단(top: 0)에 z-index를 최상위로 유지하며 붙어 있게 만들어 줘. 스크롤이 시작되는 즉시(scrollY > 0) 헤더 하단에 은은한 드롭 섀도우와 미세한 배경 블러 처리를 적용해 본문 콘텐츠와 겹쳐 보이지 않게 처리해 줘.

```




* **스플릿 레이아웃 (Split Layout)**
* **프롬프트 템플릿**:
```text
제품 상세 설명 영역에 좌우를 균등 분할하는 [스플릿 레이아웃]을 적용해 줘. 데스크톱 뷰에서는 좌측 50%에 제품 데모 스크린샷을, 우측 50%에는 기능 설명 텍스트와 체크리스트를 나란히 배치해 줘. 화면 너비가 768px 이하가 되면 좌우 배치를 해제하고 이미지가 위로, 텍스트가 아래로 배치되는 세로 스택(Vertical Stack) 구조로 자동 전환되게 해 줘.

```

### 컴포넌트 영역 (UI Components)

* **탭 (Tabs)**
* **프롬프트 템플릿**:
```text
콘텐츠 영역 내에서 화면 전환 없이 주제별 내용을 교체해 보여주는 [탭] 컴포넌트를 만들어 줘. 상단에 '개요', '기술 스펙', '가격 정책' 버튼을 배치하고, 특정 탭을 클릭하거나 키보드 좌우 방향키로 이동할 때 해당 패널만 즉시 렌더링되게 해 줘. 현재 활성화된 탭 하단에는 진한 인디케이터 라인이 부드럽게 이동하며 활성 상태를 강조해야 해.

```




* **아코디언 (Accordion)**
* **프롬프트 템플릿**:
```text
자주 묻는 질문(FAQ) 섹션을 수직 확장형 [아코디언] 컴포넌트로 구현해 줘. 각 질문 행의 우측에 회전하는 화살표 아이콘을 넣고, 질문 클릭 시 하단 답변 영역이 아래로 자연스럽게 펼쳐지며 다시 누르면 닫히도록 토글 로직을 작성해 줘. 한 번에 하나의 질문만 열리도록 설정하고 접근성을 위해 WAI-ARIA aria-expanded 속성을 연동해 줘.

```




* **모달 및 오버레이 (Modal / Dialog & Overlay)**
* **프롬프트 템플릿**:
```text
데이터 영구 삭제 버튼 클릭 시 확인을 요청하는 [모달 다이얼로그]를 화면 중앙에 띄워 줘. 모달 뒤쪽 전체 화면에는 클릭 및 뒤쪽 스크롤을 차단하는 50% 반투명 검은색 [오버레이(백드롭)]를 깔아 줘. '삭제 확인' 버튼 외에 취소 버튼 클릭, 오버레이 바깥 영역 클릭, 키보드 ESC 키 입력 시 모달이 즉시 닫히도록 닫기 조건을 바인딩해 줘.

```




* **드로어 (Drawer)**
* **프롬프트 템플릿**:
```text
우측 상단의 필터 설정 아이콘을 클릭했을 때 화면 오른쪽에서 부드럽게 슬라이드되어 나오는 [드로어] 패널을 만들어 줘. 메인 페이지의 맥락을 가리지 않도록 전체 너비의 30%(모바일은 85%)만 차지하게 하고, 드로어 외부 영역을 클릭하거나 키보드 ESC 키를 누르면 오른쪽 바깥으로 슬라이드 아웃되며 닫히도록 제약 조건을 추가해 줘.

```




* **드롭다운 (Dropdown)**
* **프롬프트 템플릿**:
```text
테이블 상단 정렬 버튼을 트리거로 하는 [드롭다운] 메뉴 컴포넌트를 작성해 줘. 버튼 클릭 시 하단으로 '최신순', '인기순', '이름순' 선택 항목 리스트 박스가 열리게 하고, 특정 옵션을 선택하면 상단 텍스트가 해당 항목으로 갱신되며 메뉴가 닫히게 해 줘. 드롭다운 외부 아무 곳이나 클릭하면 메뉴가 자동으로 닫히는(click-outside) 로직을 포함해 줘.

```




* **툴팁 (Tooltip)**
* **프롬프트 템플릿**:
```text
통계 카드 옆 물음표 도움말 아이콘에 마우스를 올리거나 키보드 포커스가 닿았을 때 부가 설명을 제공하는 [툴팁]을 구현해 줘. 아이콘의 정중앙 상단에 작고 어두운 말풍선 형태로 띄우고, 마우스가 벗어나거나 포커스를 잃으면 150ms 후 완전히 사라지게 해 줘. 화면 상단 경계와 맞닿을 경우 자동으로 아이콘 하단으로 위치가 반전되는 플리핑(flipping) 처리를 적용해 줘.

```




* **토스트 / 스낵바 (Toast / Snackbar)**
* **프롬프트 템플릿**:
```text
설정 저장 성공 시 작업 완료를 알리는 가벼운 [토스트] 알림을 구현해 줘. 화면 우측 하단(모바일은 중앙 하단)에 체크 아이콘과 함께 '변경 사항이 성공적으로 저장되었습니다' 메시지를 띄우고, 화면 노출 3초 후 페이드아웃되면서 자동으로 DOM에서 제거되게 해 줘. 우측에 즉시 닫을 수 있는 'X' 닫기 버튼도 함께 넣어 줘.

```




* **캐러셀 (Carousel)**
* **프롬프트 템플릿**:
```text
고객 리뷰 섹션에 다수의 피드백 카드를 가로 방향으로 순환 탐색하는 [캐러셀] 슬라이더를 만들어 줘. 좌우 네비게이션 화살표 버튼과 하단 인디케이터 점(dots)을 배치하고, 데스크톱에서는 3장, 모바일에서는 1장씩 보여지게 해 줘. 모바일 터치 환경을 위해 좌우 스와이프 제스처를 지원하고, 마우스 오버 시 자동 넘김(auto-play)이 일시 정지되도록 조건을 걸어 줘.

```




* **스켈레톤 로딩 (Skeleton Loading)**
* **프롬프트 템플릿**:
```text
API로부터 데이터 목록을 비동기로 패칭하는 동안 빈 화면이나 단순 스피너 대신 [스켈레톤 로딩] 화면을 표시해 줘. 실제 렌더링될 카드 레이아웃과 완벽히 동일한 크기의 프로필 원형 플레이스홀더와 텍스트 직사각형 블록을 배치하고, 밝은 회색에서 중간 회색으로 반복 이동하는 은은한 shimmer 애니메이션을 적용해 누적 레이아웃 이동(CLS)을 방지해 줘.

```

### 인터랙션 및 시각 효과 (Interactions & Effects)

* **호버 이펙트 (Hover Effect)**
* **프롬프트 템플릿**:
```text
대시보드의 데이터 카드 컴포넌트에 마우스 커서가 올라갔을 때 작동하는 [호버 이펙트]를 적용해 줘. 마우스를 올리면 카드가 translateY(-4px) 만큼 미세하게 위로 떠오르고, 하단 드롭 섀도우가 진해지며 보더 색상이 서비스 메인 포인트 컬러로 강조되게 해 줘. 마우스가 벗어날 때는 본래 상태로 부드럽게 복귀하도록 CSS transition을 연결해 줘.

```




* **스크롤 리빌 (Scroll Reveal)**
* **프롬프트 템플릿**:
```text
랜딩 페이지를 아래로 스크롤할 때 각 기능 소개 섹션이 뷰포트에 20% 이상 진입하는 시점을 감지하여 등장하는 [스크롤 리빌] 효과를 적용해 줘. 요소가 화면 밖(하단)에 있을 때는 투명도 0, translateY(30px) 상태를 유지하다가, 뷰포트에 도달하면 Intersection Observer API를 통해 투명도 1과 본래 위치로 슬라이드 업되며 자연스럽게 나타나게 해 줘.

```




* **스태거 애니메이션 (Stagger Animation)**
* **프롬프트 템플릿**:
```text
검색 결과 카드 6개가 화면에 마운트될 때 모든 요소가 동시에 번쩍이며 나타나지 않도록 [스태거 애니메이션]을 적용해 줘. 첫 번째 카드가 나타난 후 다음 카드가 0.1초(100ms) 간격의 딜레이(transition-delay / animation-delay)를 두고 순차적으로 페이드인 및 미세한 스케일 업(0.95 -> 1.0)되면서 리듬감 있게 렌더링되게 구현해 줘.

```




* **스무스 트랜지션 (Smooth Transition)**
* **프롬프트 템플릿**:
```text
모든 버튼, 링크, 탭의 호버 및 액티브 상태 변경 시 깜빡이거나 뚝뚝 끊기지 않도록 [스무스 트랜지션]을 전역 적용해 줘. CSS transition 속성을 `all 200ms cubic-bezier(0.4, 0, 0.2, 1)` 또는 `ease-in-out`으로 설정하여, 배경색, 글자색, 보더의 변화가 0.2초에 걸쳐 균일하고 매끄럽게 연결되도록 처리해 줘.

```




* **글래스모피즘 (Glassmorphism)**
* **프롬프트 템플릿**:
```text
고정 헤더 및 네비게이션 카드에 뒤 배경이 반투명하게 비치는 [글래스모피즘] 스타일을 적용해 줘. 반투명 배경색(예: rgba(255, 255, 255, 0.65))과 함께 `backdrop-filter: blur(12px)` 및 미세한 1px 반투명 화이트 보더를 부여해 줘. 단, 본문 텍스트의 가독성을 해치지 않도록 글자 명도 대비(Contrast Ratio)를 WCAG AA 기준(최소 4.5:1) 이상으로 철저히 유지해 줘.

```




* **패럴렉스 스크롤링 (Parallax Scrolling)**
* **프롬프트 템플릿**:
```text
메인 히어로 섹션의 배경 그래픽 오브젝트들에 스크롤 속도 차이를 이용한 [패럴렉스 스크롤링] 효과를 부여해 줘. 본문 텍스트가 1의 속도로 스크롤될 때 배경 원형 그래픽은 0.3의 속도로 느리게 이동하여 깊이감을 만들어 줘. 단, 멀미를 유발하지 않도록 이동 폭을 최소화하고, OS 설정에서 움직임 줄이기(prefers-reduced-motion: reduce)가 켜진 환경에서는 이 효과를 완전히 비활성화해 줘.

```




* **스크롤 스냅 (Scroll Snap)**
* **프롬프트 템플릿**:
```text
전체 화면(100vh) 슬라이드 형태의 제품 스토리텔링 페이지를 만들고 CSS [스크롤 스냅]을 적용해 줘. 부모 컨테이너에 `scroll-snap-type: y mandatory`를 적용하고, 각 풀스크린 섹션에는 `scroll-snap-align: start`를 지정해 줘. 사용자가 마우스 휠이나 트랙패드 스크롤을 놓았을 때 화면이 중간에 어정쩡하게 걸치지 않고 다음 섹션의 시작점에 딱 맞춰 정렬되도록 해 줘.

```




* **마이크로 인터랙션 (Micro-interaction)**
* **프롬프트 템플릿**:
```text
'즐겨찾기' 및 '저장' 버튼에 사용자의 인터랙션 즉시 직관적인 시각 피드백을 주는 [마이크로 인터랙션]을 구현해 줘. 버튼 클릭 시 즉시 스피너가 돌며 로딩 상태를 보여주고, 저장이 완료되면 0.2초 동안 버튼이 1.1배 살짝 커졌다가 줄어들며 하트(또는 체크) 아이콘이 초록색으로 채워지는 바운스 효과를 연출해 줘.

```

### 복합 적용: 실전 종합 프롬프트 (랜딩 & 대시보드)

개별 요소들을 결합하여 완성도 높은 단일 페이지 프론트엔드를 한 번에 요청할 때 사용할 수 있는 고도화된 프롬프트입니다.

* **고성능 랜딩 페이지 단일 프롬프트**
```text
React와 Tailwind CSS를 활용해 모던한 SaaS 랜딩 페이지를 작성해 줘.

1. 상단: 페이지가 스크롤되어도 상단에 고정되는 [스티키 헤더]를 적용하고, 반투명 블러 효과의 [글래스모피즘] 스타일을 입혀 줘.
2. 첫 화면: 강렬한 헤드라인, 2줄의 서브 카피, 눈에 띄는 [CTA 버튼]이 포함된 [히어로 섹션]을 구성해 줘.
3. 기능 소개: 서비스 핵심 기능을 시각적으로 요약하기 위해 비대칭 [벤토 그리드]를 적용하고, 각 카드가 화면 뷰포트에 도달할 때 아래에서 위로 나타나는 [스크롤 리빌]과 0.1초 단위의 [스태거 애니메이션]을 적용해 줘.
4. 카드 인터랙션: 각 기능 카드에 마우스를 올리면 살짝 떠오르는 [호버 이펙트]와 200ms 속도의 [스무스 트랜지션]을 부여해 줘.
5. FAQ & 설정: 질문 목록은 접고 펼칠 수 있는 [아코디언]으로 작성하고, 상단 프로필 클릭 시 오른쪽에서 [드로어]가 열려 사용자 환경설정을 조정할 수 있게 해 줘. ESC 키 입력 시 드로어가 닫혀야 해.

```


* **데이터 분석 대시보드 단일 프롬프트**
```text
Next.js와 TypeScript 기반의 데이터 분석 대시보드 메인 뷰를 개발해 줘.

1. 레이아웃: 좌측에 260px 폭의 네비게이션이 고정된 [사이드바 레이아웃]을 기본 구조로 잡고, 본문 콘텐츠는 3열 [반응형 레이아웃]으로 구성해 줘.
2. 비동기 처리: 차트 데이터와 요약 메트릭을 불러오는 동안 빈 화면 대신 실제 박스 규격과 동일한 [스켈레톤 로딩] 애니메이션을 먼저 렌더링해 줘.
3. 데이터 카드: 핵심 지표 카드들은 정돈된 [카드 레이아웃]으로 배치하고, 각 지표 우측 상단 도움말 아이콘에 마우스를 올리면 산출 공식이 표시되는 [툴팁]을 붙여 줘.
4. 피드백 및 모달: 필터 조건을 변경하고 저장 버튼을 누르면 버튼 자체에 체크 아이콘이 튀어나오는 [마이크로 인터랙션]을 부여하고, 화면 하단에 3초간 머무는 [토스트] 알림을 띄워 줘. 데이터 초기화 버튼 클릭 시에는 배경을 어둡게 막는 [오버레이]와 중앙 [확인 모달]을 띄워 최종 승인을 받아 줘.

```
